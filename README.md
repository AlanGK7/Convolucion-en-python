# señales Sistemas LTI y Convolución 
Este proyecto consistió en el desarrollo de una serie de scripts en Python para la Experiencia 2: Sistemas LTI y Convolución. El trabajo se dividió en tres partes principales.Primero, se crearon los generadores para un conjunto de señales fundamentales, tanto periódicas (senoidal, cuadrada, triangular, diente de sierra) como aperiódicas (exponencial creciente/decreciente, impulso, escalón y sinc). 

En segundo lugar, se implementó un módulo para calcular la energía y la potencia media de cualquier señal de entrada, un requisito clave para el análisis.Finalmente, se utilizaron estas señales para realizar la operación de convolución y demostrar experimentalmente las propiedades de los Sistemas Lineales e Invariantes en el Tiempo (LTI). Específicamente, se verificó la propiedad conmutativa **(x*h = h*x)** intercambiando la señal de entrada y la respuesta al impulso en cinco combinaciones. 

Además, se demostraron las propiedades de linealidad (aplicando un factor de escala) y de invarianza temporal (aplicando un corrimiento) para confirmar el comportamiento LTI del sistema.
